# Bubble Wand

This is a 3D printed bubble wand I designed for my daughters and their friends to use. 

## Wand

The [Bubble_Wand.scad](./Bubble_Wand.scad) file can be used to generate the wand.  You must render and export the Handle Ring separately and glue them together with Superglue


## Rack

The [Wand_rack_mount.scad](./Wand_rack_mount.scad) to be mounted to the side of my bubble table.



## Bubble Solutions

In the process of designing this wand, I also started experimenting with a custom [bubble solution recipe](Bubble_Solution.md)
